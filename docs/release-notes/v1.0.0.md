**Aoze 1.0.0**: fast, simple, local image, GIF and clip enhancement for Windows 10/11 (x64).

- Image & GIF: enlarge (waifu2x), clean up, compress, Discord sizes.
- Clip: Clean-up (Real-ESRGAN anime video model / waifu2x), Smooth Motion 60/120 FPS (RIFE, never across scene cuts), motion blur from the motion, HDR (keep / tone map / HDR10), Look.
- Convert: clip ↔ GIF, GIF → video, images → GIF.
- Everything runs on your PC: no upload, no account. Works on NVIDIA, AMD and Intel GPUs (Vulkan), CPU fallback.

Download **Aoze_1.0.0_x64-setup.exe**, run it, done (FFmpeg and every engine are included).
The installer is per-user (no admin rights). It is not code-signed yet, so Windows SmartScreen
may show "Windows protected your PC": choose "More info", then "Run anyway".

SHA-256 of every file: `SHA256SUMS.txt`. Third-party licences: `THIRD_PARTY_NOTICES.md` and
`THIRD_PARTY_LICENSES.txt`.
