La licence d'Aoze

Le code source d'Aoze (l'application et ce site) est publié sous la licence MIT, Copyright (c) 2026 zero. Le texte officiel est dans le fichier LICENSE du dépôt, et il est reproduit en bas de cette page.

Ce que vous pouvez faire

  • Utiliser Aoze gratuitement, pour un usage personnel ou commercial.
  • Lire, copier et modifier son code.
  • Redistribuer Aoze, modifié ou non, gratuitement ou non, et l'inclure dans un autre projet.

La seule condition

Toute copie d'Aoze, ou de parties importantes de son code, doit garder la mention de copyright et le texte de la licence MIT. Si vous publiez une version modifiée, merci de ne pas la présenter comme la version officielle.

Sans garantie

La licence fournit Aoze « tel quel », sans garantie, et exclut la responsabilité des auteurs. Les conditions d'utilisation expliquent ce point en termes simples.

Redistribuer l'installeur

Aoze lance FFmpeg comme un programme séparé, sans s'y lier : le code d'Aoze reste sous licence MIT. Mais l'installeur contient FFmpeg, qui est sous licence GPL-3.0. Si vous redistribuez l'installeur complet, vous devez aussi respecter la GPL pour FFmpeg : garder sa licence et donner accès à son code source.

Le code source exact de FFmpeg utilisé est indiqué dans THIRD_PARTY_NOTICES.md (code de FFmpeg, scripts de compilation BtbN). Si un de ces liens ne fonctionne plus, ouvrez une issue et le code correspondant vous sera fourni.
