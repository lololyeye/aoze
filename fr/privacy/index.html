Vos données, simplement

Ce que l'application Aoze et ce site font, et ne font pas, avec vos données. Tout ce qui suit a été vérifié dans le code source d'Aoze.

Dernière mise à jour : 31 octobre 2026

En bref

  • Aoze traite vos images, GIF et clips sur votre PC. Ils ne sont envoyés nulle part.
  • La seule connexion que l'application fait d'elle-même est la recherche de mises à jour sur GitHub, que vous pouvez désactiver.
  • Le site mesure sa fréquentation lui-même, sans service tiers ni publicité. Il n'enregistre pas votre adresse IP, et vous pouvez refuser en un clic.
  • Le site est hébergé en France par o2switch, les téléchargements par GitHub : comme tout hébergeur, chacun voit votre adresse IP.

Qui est responsable

Aoze et ce site sont publiés par Zero (voir les mentions légales). Pour toute question sur vos données : contact@aoze.fr.

L'application Aoze

Vos fichiers restent sur votre PC

Les images, GIF et clips que vous ouvrez sont traités sur votre ordinateur, par des programmes installés avec Aoze (waifu2x, FFmpeg, RIFE, Real-ESRGAN). Aoze n'envoie aucun fichier, aucune image et aucun nom de fichier sur Internet. Il n'y a pas de compte, pas de télémétrie, pas de rapport de plantage automatique et pas de publicité.

Ce qu'Aoze enregistre sur votre PC

Réglages

Vos préférences (langue, préréglages, dossier de sortie…). Dans %APPDATA%\app.aoze.

Historique

Pour chaque fichier traité : son chemin, celui du résultat, les dimensions, les tailles et les réglages utilisés. Effaçable depuis l'écran Historique. Dans %APPDATA%\app.aoze.

Mesures de performance

Les vitesses mesurées sur votre matériel, pour adapter les réglages. Dans %APPDATA%\app.aoze.

Journal

Un fichier aoze.log (2 Mo au plus) qui peut contenir des chemins de fichiers et le nom de votre carte graphique. Dans %LOCALAPPDATA%\app.aoze\logs.

Cache

Aperçus, fichiers de travail temporaires, images collées et mises à jour téléchargées. Dans %LOCALAPPDATA%\app.aoze.

Ces fichiers ne quittent jamais votre PC. À la désinstallation, cochez l'option de suppression des données de l'application pour tout effacer.

Rapport de diagnostic

Si vous cliquez sur le bouton de copie du diagnostic, Aoze copie dans votre presse-papiers un rapport technique (versions, carte graphique, fin du journal). Rien n'est envoyé : c'est vous qui décidez de le partager. Il peut contenir des chemins de dossiers avec votre nom d'utilisateur Windows : relisez-le avant de le publier.

Composants Windows

L'interface d'Aoze s'affiche avec Microsoft Edge WebView2, un composant de Windows. Si votre PC ne l'a pas, l'installeur le télécharge depuis Microsoft. Ce composant suit les règles de Microsoft. Les liens (GitHub, Ko-fi) s'ouvrent dans votre navigateur.

Mises à jour

Quand Aoze s'ouvre, si l'option Rechercher les mises à jour est activée (elle l'est par défaut), l'application lit le fichier latest.json de la dernière version publiée sur GitHub. Si une nouvelle version existe, elle vous la propose ; elle ne la télécharge que si vous le demandez, depuis GitHub Releases.

Comme pour toute connexion, GitHub reçoit les données techniques de la requête (adresse IP, date, fichier demandé). Aoze n'y ajoute aucun fichier, aucun identifiant et aucune donnée d'utilisation. Vous pouvez désactiver cette option dans les Réglages, section Mises à jour.

Le site

Ce site est fait de pages statiques, sans formulaire, sans compte et sans publicité. Les polices et les images sont servies par le site lui-même (pas de Google Fonts, pas de vidéo intégrée d'un autre site).

Hébergement

Le site est hébergé en France par o2switch. Comme tout hébergeur, o2switch enregistre les données techniques de chaque visite (adresse IP, navigateur, page demandée, date) dans les journaux du serveur, pour afficher le site et le protéger. Nous ne nous en servons pas pour suivre les visiteurs ni pour mesurer l'audience.

Version et nombre de téléchargements

Les pages d'accueil et de téléchargement demandent à l'API de GitHub (api.github.com) le numéro de la dernière version et le total des téléchargements, directement depuis votre navigateur. GitHub reçoit donc votre adresse IP et des informations sur votre navigateur. Aucun cookie n'est utilisé pour cela.

Téléchargement

Le bouton Télécharger passe par aoze.fr/get/, qui note la demande (voir la mesure d'audience ci-dessous) puis vous envoie vers le fichier hébergé sur GitHub Releases. GitHub compte aussi les téléchargements de chaque fichier. Nous ne savons pas si le téléchargement s'est terminé, ni qui l'a fait.

Mesure d'audience

Pour savoir quelles pages servent, d'où viennent les visiteurs et si le téléchargement est facile à trouver, le site compte ses visites lui-même, sur notre serveur chez o2switch. Aucun service de mesure tiers, aucune publicité, aucun suivi d'un site à l'autre : ces statistiques ne servent qu'à améliorer ce site, ne sont ni vendues ni partagées, et ne sont pas croisées avec d'autres données.

Ce qui est noté

La visite

Les pages vues, la page d'arrivée et de sortie, le temps où chaque page est affichée, la langue du site.

La provenance

Le nom du site d'où vous venez (par exemple discord.com, sans le reste de l'adresse), et les paramètres de campagne utm_ d'un lien partagé.

L'appareil

Ordinateur, mobile ou tablette, le nom du navigateur et du système, déduits de l'en-tête que tout navigateur envoie. Pas de version précise, pas d'empreinte du navigateur.

Le pays

Déduit de votre adresse IP avec une base de données installée sur notre serveur (IP to Country Lite de DB-IP, licence CC BY 4.0). L'adresse IP elle-même n'est pas enregistrée.

Le téléchargement

Si le bouton Télécharger a été vu, cliqué, si l'avertissement de Windows a été accepté et si l'installeur a été demandé, avec sa version.

Pour reconnaître une visite qui continue ou un visiteur qui revient, le site dépose un cookie aoze_v : un identifiant tiré au hasard, qui ne dit rien de vous (voir les cookies ci-dessous). Contre les abus, une empreinte chiffrée de l'adresse IP compte les envois par minute ; elle est effacée dans l'heure.

Rien n'est mesuré si votre navigateur envoie le signal Do Not Track ou Global Privacy Control, ni pour les robots.

Refuser la mesure

Ce choix vaut pour ce navigateur et se garde 13 mois.

Cookies et stockage local

Le site n'utilise aucun pixel publicitaire, aucun traceur d'un autre site et aucun cookie tiers. Il peut déposer deux cookies, propres à aoze.fr :

  • aoze_v : l'identifiant aléatoire de la mesure d'audience. Il dure 13 mois à partir de la première visite et n'est jamais prolongé. Seul le serveur du site peut le lire.
  • aoze_optout : seulement si vous refusez la mesure, pour retenir ce choix 13 mois.

Ce cookie de mesure ne sert qu'aux statistiques de ce site et respecte les conditions de la CNIL pour être dispensé de consentement : c'est pour cela qu'il n'y a pas de bannière. Vous pouvez tout de même le refuser plus haut, ou effacer les cookies du site dans votre navigateur.

Une valeur peut aussi être enregistrée dans le stockage local : aoze-lang, quand vous changez de langue avec le bouton EN / FR. Elle sert uniquement à retenir ce choix et n'est jamais envoyée.

Services tiers

  • GitHub héberge le code et les téléchargements, et répond à la recherche de mises à jour. Déclaration de confidentialité de GitHub.
  • Ko-fi reçoit les dons volontaires. Le site ne fait qu'un lien vers ko-fi.com : aucun script Ko-fi n'est chargé ici, et le paiement se fait entièrement chez Ko-fi et ses prestataires de paiement. Nous ne voyons jamais vos données de paiement. Politique de confidentialité de Ko-fi.
  • Microsoft fournit WebView2, utilisé par l'application pour afficher son interface.
  • DB-IP publie la base qui donne le pays d'une adresse IP. Nous la téléchargeons sur notre serveur chaque mois : aucune adresse ne leur est envoyée.

Quand vous ouvrez un de ces services, ses propres règles s'appliquent.

Si vous nous écrivez

Si vous nous envoyez un e-mail, nous recevons votre adresse et votre message, et nous les utilisons uniquement pour vous répondre. Les issues GitHub sont publiques et soumises aux règles de GitHub.

Finalités et bases légales

  • Répondre à vos messages : intérêt légitime (article 6.1.f du RGPD), pouvoir répondre aux personnes qui nous écrivent.
  • Héberger le site chez o2switch et distribuer Aoze via GitHub : intérêt légitime, publier le site et distribuer Aoze. o2switch héberge le site pour nous ; GitHub traite les données techniques de ses serveurs (adresse IP, journaux) en tant que responsable indépendant, selon sa propre déclaration de confidentialité.
  • Rechercher les mises à jour : intérêt légitime, vous proposer les correctifs et les nouvelles versions. La demande va directement à GitHub, nous n'en recevons rien, et vous pouvez la désactiver dans les Réglages.
  • Mesurer l'audience du site : intérêt légitime, comprendre comment le site est utilisé pour l'améliorer. Le cookie de mesure est dispensé de consentement (article 82 de la loi Informatique et Libertés) parce qu'il est limité à cette mesure ; vous pouvez vous y opposer à tout moment.

Durées de conservation

  • Vos e-mails : 3 ans après le dernier échange, puis ils sont supprimés.
  • Mesure d'audience : le détail des visites et des demandes de téléchargement 6 mois, puis seulement des totaux par jour, sans identifiant, 25 mois au plus. Le cookie aoze_v dure 13 mois.
  • Journaux de GitHub : selon la déclaration de GitHub. Nous ne les conservons pas, nous n'y avons pas accès.
  • Données de l'application : sur votre PC, jusqu'à ce que vous les effaciez.

Transferts hors de l'Union européenne

GitHub, Inc. est une société basée aux États-Unis : les données techniques des demandes faites à GitHub (version affichée sur le site, téléchargements, recherche de mises à jour) peuvent y être traitées. Le site lui-même est hébergé en France. GitHub est certifié au Data Privacy Framework UE–États-Unis, qui encadre ces transferts.

Vos droits

Selon la loi qui s'applique à vous (notamment le RGPD), vous pouvez demander l'accès à vos données, leur correction, leur effacement, la limitation de leur traitement, leur portabilité, ou vous opposer à leur traitement. Écrivez à contact@aoze.fr.

Les mesures d'audience ne sont liées qu'à l'identifiant aléatoire du cookie : nous ne pouvons pas les rattacher à votre nom. Refuser la mesure supprime ce cookie. Une demande portant sur les journaux de GitHub ou sur un paiement Ko-fi doit souvent être adressée à ces services. Vous pouvez aussi déposer une réclamation auprès de l'autorité de protection des données de votre pays, en France la CNIL.

Modifications

Si Aoze ou le site changent leur façon de traiter des données, cette page sera mise à jour avant, et la date en haut de page changera. L'historique de cette page est public dans le dépôt GitHub.
