Téléchargement

Les seules sources officielles d'Aoze sont les versions publiées sur GitHub et la page Télécharger de ce site, qui pointe vers elles. Un fichier obtenu ailleurs a pu être modifié.

Être hébergé sur GitHub ne garantit pas qu'un fichier est sans danger. L'installeur n'a pas encore de signature de code. Pour vérifier que votre fichier est bien celui qui a été publié, comparez son empreinte SHA-256 avec celle affichée sur la page Télécharger.

Aoze fonctionne sur Windows 10 et 11, 64 bits.

Mises à jour

Aoze peut rechercher une nouvelle version à son ouverture (option désactivable). Une mise à jour n'est installée que si vous l'acceptez, et seulement si sa signature, son empreinte SHA-256 et sa taille correspondent à la version publiée. Aucune mise à jour n'est garantie : le projet peut évoluer ou s'arrêter.

Vous êtes responsable des fichiers que vous ouvrez : vous devez avoir le droit de les utiliser et de les modifier, en particulier pour des images de personnes ou des œuvres protégées.

L'agrandissement et l'interpolation créent des détails et des images qui n'existaient pas dans l'original. Ne présentez pas un résultat comme une image d'origine quand cela compte (preuve, document officiel). Gardez toujours une copie de vos originaux.
