# Aoze website

The public site for Aoze: https://lololyeye.github.io/aoze/

It lives apart from the desktop app: its own `package.json`, nothing imported from `src/` or `src-tauri/`.
Built with [Astro](https://astro.build) as plain static HTML, with a few small scripts (before/after slider,
demo tabs, mobile menu, download page refresh).

```bash
npm install
```

```bash
npm run dev
```

```bash
npm run build
```

## Pages

- `/`: product, before/after, features, editors, performance, privacy, open source.
- `/download/`: the latest GitHub release (version, date, size, SHA-256, notes).
- `/credits/`: third-party components and their licenses (mirrors `THIRD_PARTY_NOTICES.md`).

Every page exists in English (root) and French (`/fr/`). The pages themselves are in `src/views/`;
`src/pages/` only routes each language to them, and all text is in `src/i18n/ui.ts`.
A French browser landing on an English page is sent to the French one; the EN / FR switch in the
header remembers the reader's choice (localStorage), which then wins over the browser language.

## Release data

At build time `src/lib/release.ts` reads `releases/latest` from the GitHub API and picks the
`*_x64-setup.exe` asset. The SHA-256 is the digest GitHub computes for that asset. If the API is
unreachable, `src/data/release-fallback.json` (a snapshot of a real release) is used.
The download page also refreshes these values in the browser, so a new release shows up before the next build.

Publishing a release on GitHub triggers `.github/workflows/website.yml`, which rebuilds and deploys the site.
Keep the installer name in the form Tauri produces (`Aoze_<version>_x64-setup.exe`).

## Demo media and screenshots

- `public/demo/`: generated by `npm run demo` (`demo/build-demo.mjs`) from `demo/scene.svg`, with the waifu2x,
  RIFE and FFmpeg binaries Aoze ships (from an installed `Aoze/` folder or `src-tauri/resources`).
  The image is enlarged 4× with noise reduction High; the clip goes from 24 to 60 FPS with RIFE v4.6.
- `public/shots/`: screenshots of Aoze 1.0.0 itself (English UI, Windows 11), cropped to the window.
- `public/og.png`: rendered from `demo/og.svg` with FFmpeg.
